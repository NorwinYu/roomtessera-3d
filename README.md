# 室演 3D · RoomTessera

> 浏览器里的 3D 家装规划器：导入户型图，生成可交互的三维空间，自由摆放家具、材质与灯光。

**在线演示：** https://norwinyu.github.io/roomtessera-3d/

RoomTessera 3D 是一个**纯前端、本地优先**的室内设计工作台。它把一张户型图转换成可环绕查看的 3D 场景，并提供房间识别、家具布置、材质灯光、方案保存与效果图导出。无需账号，图片和方案不会上传到服务器。

**项目状态：v0.1 / 早期预览。** 自动墙体和房间切分属于启发式识别，只作为草稿；需要精确墙体时，请使用内置的手动墙线工具。

## 功能

### 户型与空间

- **户型图导入**：支持 JPG / PNG / WEBP，自动估算户型范围、地面轮廓和空间比例。
- **3D 场景生成**：生成地面、墙体、建筑基座和相机视角，支持 3D 透视与近正交平面视图。
- **空间切分**：自动识别独立空间、计算面积，可在平面视图中重命名房间标签。
- **手动墙线**：补画水平/垂直墙体、点击或拖动擦除、清空全部自动墙体；支持 10 cm 网格/墙线吸附和 20 步撤销。
- **地面测距**：在 3D 或平面视图中拾取两点，显示实际距离。
- **户型底图与网格**：可叠加原始户型图、显示辅助网格，方便对照调整。

### 家具与装修

- **程序化家具**：沙发、床、餐桌、衣柜、书架、灯具、绿植、地毯等 15 类家具，无需外部模型文件。
- **拖拽布置**：在 3D / 平面视图中直接拖动家具；右侧面板可精确调整位置、旋转、缩放和颜色。
- **碰撞提示**：拖动时实时检测墙体、其它家具和空间边界，重叠时给出红色提示。
- **智能落位**：新增单品或整套家具时，自动寻找可放置的空位。
- **材质与灯光**：6 种地面材质、6 种墙面色、3 种光照氛围、4 套全屋风格预设。
- **剖切视图**：降低墙体高度俯视全屋，随时切回完整墙高。

### 保存与工程

- **本地自动保存**：方案保存在浏览器 localStorage，刷新不丢失。
- **导入 / 导出**：支持 `.roomtessera.json` 方案文件；兼容旧版 `.roomtrial.json`；可导出当前视角 PNG。
- **异常恢复**：方案结构校验、页面级错误边界、缓存重置入口。
- **按需加载**：3D 运行时独立分包，首屏 UI 优先呈现。
- **无后端**：识别、渲染、存储全部在浏览器完成。

## 快速开始

环境要求：Node.js 20+。

```bash
npm install
npm run dev
```

打开终端提示的地址即可。也可以直接点击首页的「打开示例空间」体验完整流程。

生产构建：

```bash
npm run build
npm run preview
```

## 使用流程

1. **导入户型图**：拖入窗口，或点击「上传户型图」。建议使用正视角、背景干净的彩色户型图。
2. **检查比例**：在「户型 → 空间比例」按实际尺寸校正总宽；已有家具会随比例缩放。
3. **修正墙体**：自动墙体只是草稿。可在「户型」里清空后手动画墙，或用「手动修正墙体」擦除/补墙。
4. **装修与布置**：在「装修」中切换材质、墙色和光照；在「家具」中添加单品或套装并拖动布置。
5. **保存与导出**：顶部保存到本地；「导出效果图」下载 PNG；菜单中可导出/导入完整方案 JSON。

## 技术栈

- React 18 + TypeScript + Vite
- Three.js + @react-three/fiber + @react-three/drei
- Zustand：状态、撤销栈、本地持久化
- Canvas 2D：户型图色彩分割与轮廓处理
- 程序化材质与家具几何，无外部图片/模型依赖
- 纯 CSS 设计系统，无 UI 框架

## 实现说明

户型识别在浏览器 Canvas 上完成，主要步骤：

1. **色彩分割**：按 HSV/亮度提取暖色地面，排除深色墙线、文字和背景。
2. **地面补洞**：填充房间内的文字、家具符号等孔洞，保留墙体边界。
3. **边界与空间**：从地面掩膜提取轮廓，切分连通空间并估算面积。
4. **墙体轮廓**：从墙体栅格提取连续轮廓，做正交化与简化，再挤出为 3D 墙体。
5. **实时渲染**：Three.js 负责场景、相机、阴影、家具与交互。

> 自动识别是启发式算法，不依赖云端模型。图纸质量、墙面颜色和标注密度都会影响结果；复杂户型请在识别后使用手动墙线修正。

## 隐私与数据

- 图片解析、3D 渲染和方案保存均在本地浏览器完成，没有上传接口。
- 方案默认写入 localStorage；清理浏览器数据会丢失，请同时导出 `.roomtessera.json`。
- 仓库默认忽略 `.examples/`、`screenshots/`、`artifacts/`、`exports/` 以及常见图片/文档文件，避免个人户型图、截图和导出物进入版本库。
- 提交前建议执行 `git status` 和 `git diff --cached`，确认没有带入个人图片或本地路径。

## 已知限制

- 自动墙体与房间切分不保证与图纸完全一致，可能出现短墙头、厚度不均或局部缺墙；请把它当作草稿。
- 手动墙体只支持水平/垂直方向，不支持任意角度墙。
- 自动面积基于图像比例估算，需用「空间比例」校正。
- 家具碰撞为提示制，不强制阻止重叠。
- 图像解析在主线程完成，超大图片可能短暂卡顿；解析过程中可取消。
- localStorage 有容量限制，重要方案请导出 JSON 备份。
- 无 WebGL 时只显示降级提示。
